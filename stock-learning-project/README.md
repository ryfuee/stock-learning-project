# 学习炒股长期项目

这是一个用于长期学习股票投资与交易的个人项目。目标不是追逐短期暴利，而是建立一套可复盘、可验证、可迭代的学习系统。

> 说明：本项目只用于学习、记录和训练，不构成任何投资建议。真实交易前，请确认自己理解风险，并遵守所在地适用法律法规。

## 项目目标

1. 建立基础知识体系：市场机制、财务报表、估值、技术分析、行为金融、风险管理。
2. 训练交易流程：观察、假设、入场计划、风险控制、退出规则、复盘。
3. 形成个人风格：区分长期投资、波段交易、短线交易，逐步筛选适合自己的方法。
4. 用数据约束自己：每次决策有记录，每周/月有复盘，每个策略先模拟验证。

## 推荐使用方式

每周固定 3 次学习或复盘，每次 30-90 分钟。

- 周一：市场观察与学习
- 周三：案例研究或策略实验
- 周五/周末：交易日志整理与周复盘

## 目录结构

- `00-inbox/`：临时想法、文章摘录、问题池。
- `01-foundations/`：基础知识笔记。
- `02-market-notes/`：市场观察、行业/公司跟踪。
- `03-paper-trading/`：模拟交易计划与记录。
- `04-trade-journal/`：真实或模拟交易日志。
- `05-reviews/`：周复盘、月复盘、季度复盘。
- `06-strategy-lab/`：策略假设、回测想法、验证结果。
- `07-risk/`：风险规则、仓位规则、心理纪律。
- `templates/`：可复制使用的模板。
