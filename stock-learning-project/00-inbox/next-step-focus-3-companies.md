# 下一步：3家公司观察训练

范围：中国海油、中国船舶、沪电股份。

## 第 1 步：今天完成

阅读三张研究卡：

- `02-market-notes/research-card-600938-cnooc.md`
- `02-market-notes/research-card-600150-cssc.md`
- `02-market-notes/research-card-002463-wus.md`

读完后，用自己的话各写一句：

- 中国海油靠什么赚钱？
- 中国船舶靠什么赚钱？
- 沪电股份靠什么赚钱？

## 第 2 步：明天开始

每天收盘后，在 `02-market-notes/focus-companies.md` 的“每日观察表”里填一行。

只填事实：

- 股价涨跌
- 所属板块强弱
- 今天有没有重要消息
- 自己是否看懂

## 第 3 步：3 天后

从 3 家里选 1 家，写第一笔模拟交易计划。

要求：

- 写买入理由
- 写失效条件
- 写止损位置
- 写最多亏多少钱

注意：还是不做真实交易。
